## 📌 Visión General

Clasificador de riesgo de tres niveles (Alto, Medio, Bajo) que permite identificar si una edificación se encuentra en condiciones aptas para el ingreso, el análisis es procesado por un modelo que toma varias entradas de una misma fotografía, angulo de inclinación de la edificación, y medición de cualquier tipo de grieta.
